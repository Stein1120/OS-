# xv6-labs-2021 课程设计

基于 MIT xv6-labs-2021 完成。各实验保存在独立分支：

| 分支 | 实验 |
|---|---|
| `util` | Utilities |
| `syscall` | System calls |
| `pgtbl` | Page tables |
| `traps` | Traps |
| `cow` | Copy-on-Write |
| `thread` | Multithreading |
| `net` | Network driver |
| `lock` | Locks |
| `fs` | File system |
| `mmap` | mmap |

切换到相应分支后，可使用 `make qemu` 启动 xv6，使用该分支的 `grade-lab-*` 脚本运行测试。

MIT 原始项目说明见根目录的 `README`。
